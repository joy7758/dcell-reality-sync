# Research Questions v0.1

## Primary question

**RQ1:** 在长时运行的 Agentic World Model 中，带身份、来源、状态和变化历史的 Cell 记录，
是否比匹配的版本化文档、RAG、知识图谱或 Agent Memory 基线更可靠地识别陈旧与偏差？

## Secondary questions

- **RQ2:** 显式绑定 Observation、Claim 和 Evidence reference 是否改善独立复核？
- **RQ3:** 保留冲突和未知是否降低无依据的“已同步”判断？
- **RQ4:** 时间窗口、来源可用性和覆盖率是否足以表达同步质量，还是会制造伪精确？
- **RQ5:** 增加 Cell 对象层的维护与治理成本是否高于其可追溯性收益？

## 可证伪条件

研究假设在以下情况下应被削弱或拒绝：

1. 匹配基线在陈旧识别、冲突保留和状态重建上达到相同或更好结果；
2. Schema 无法阻止来源缺失、时间未知或证据不足时的强结论；
3. 独立复核者无法从记录重建评估依据；
4. 对象层显著增加成本，却没有预先声明的可测量收益；
5. 实验结果依赖人工选择有利来源或删除失败记录。

当前没有执行这些实验，所有答案保持 `NOT_ASSESSED`。
