# Claims and Nonclaims

## 当前可支持主张

- 本仓库包含 Reality Synchronization Layer 的有界研究原型说明。
- 本仓库定义了一个机器可读的 `Cell Schema v0.1` 研究草案。
- Schema 明确表达来源、观察、主张、证据引用、状态、冲突、不确定性和同步评估边界。
- 合成样例可以用于结构验证和未来负例设计。
- 本仓库包含 Frozen LLM、RAG 和 DCell research condition 三组对照的 Reality Drift Benchmark v0.1 设计草案。

## 当前不可支持主张

- 已实现 Reality Synchronization Runtime、服务、平台或世界模型；
- 已经把 Agent 或 World Model 与现实持续同步；
- Schema 中的记录是真实、完整、已验证或最新的；
- 已创建真实 Cognitive Cell、DCell 或 DBOS Entity；
- 已改变 DCell Core 定义；
- 已实现或执行 Benchmark、获得比较结果、证明 DCell 优越、完成科学验证、外部采用或生产部署；
- 已提交 DBA 报备、获得项目组合准入、DBOS 注册或 SAEE 评价；
- 本项目拥有 Evidence、Truth、Authorization、Certification 或执行权威。

## 安全表述

可以说：

> 我们创建了一个面向智能体世界模型现实同步问题的文档与 Schema 研究原型。

不可以说：

> 我们实现了能让世界模型与现实保持同步的平台。
