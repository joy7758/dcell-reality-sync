# dcell-reality-sync Agent Entry

## Repository role

This repository is a documentation-and-schema-only research prototype for a
candidate Reality Synchronization Layer for Agentic World Models.

It is not a platform, Runtime, world model, Agent framework, registry, truth
store, synchronization service, or DCell Core definition.

## Mandatory startup order

1. Read `STATUS.json` as the only current repository status source.
2. Read `README.md` for the human entry and scope.
3. Read `agent-index.json` for the machine entry.
4. Read `docs/research-scope.md` and `docs/architecture.md`.
5. Read `governance/reuse-overlap-ownership-review.md`.
6. Read `governance/agent-recommendation-gate.json`.
7. Read `schema/README.md` before interpreting `schema/cell.schema.json`.
8. Read `docs/claims-and-nonclaims.md` before making project claims.
9. Read `evidence/source-manifest.json` before citing source relationships.
10. Read `governance/dba-filing-candidate.json` before any DBA claim.

## Allowed work

- Refine research questions, hypotheses, conceptual architecture, and schemas.
- Add synthetic examples, negative cases, and non-executing validation notes.
- Preserve conflicts, uncertainty, stale observations, and unknowns.
- Prepare local governance and DBA filing candidates.

## Prohibited work

- Do not create a Runtime, synchronization daemon, API service, database,
  platform, registry, Agent, model, scheduler, controller, or production path.
- Do not mutate a real-world system, external model, DCell source repository,
  DBA cockpit, DBOS, SAEE, or evidence authority from this repository.
- Do not claim scientific validation, DCell classification, DBA admission,
  external adoption, deployment, production readiness, or certification.
- Do not commit, push, publish, deploy, or submit externally unless the owner
  separately authorizes that exact action.
